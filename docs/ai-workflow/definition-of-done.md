# Definition of Done（完成定义）

一项功能/修复在声明「完成」前必须满足：

## 功能

- [ ] Intake 中的 Success criteria 全部满足或已书面降级
- [ ] 租户隔离与权限路径已按 Verify 测过（若涉及数据/鉴权）

## 代码

- [ ] 平台/应用目录边界正确
- [ ] 无明显死代码、无密钥入库
- [ ] 与仓库现有风格一致

## 验证

- [ ] 至少一种自动化或可复现手工验证有证据
- [ ] 已知失败有记录

## 文档

- [ ] `docs/` 对应层级已更新，或显式「无文档影响」
- [ ] 新应用/新权限码已进入 module-map（若适用）

## 交接

- [ ] 提供 Handoff 摘要与 Follow-ups
