# 环境约定

| 环境 | 用途 | 数据 |
|------|------|------|
| local | 开发 | 可销毁 |
| staging | 预发 | 接近生产，无真实密钥进 git |
| production | 生产 | 密钥托管；变更需评审 |

## 配置原则

1. 仓库内仅 `*.example` 或 `configs/*.example.*`
2. 必填项在文档列出：DB、缓存、JWT 密钥、CORS、web API base URL
3. 租户相关特性开关（若有）按环境记录默认值
